# 圖資與實勘資料維護

## 公開圖資

`public/data/campus.json` 內含臺大建物中心、輪行臺北斜坡道及 OpenStreetMap 小範圍路網。網頁讀取此資料快照，公開 API 僅於人工執行更新指令時連線。

```powershell
npm.cmd run data:refresh
npm.cmd run data:refresh -- --offline
npm.cmd run data:refresh -- --dry-run
```

更新腳本將各來源分開處理。某來源失敗時保留其舊資料與取得日期，標記 `cached`。三個來源全部失敗時，原資料與日期均保留。寫入前會驗證資料，再用暫存檔原子替換。`--offline` 僅驗證現有資料，`--dry-run` 連線取得資料但不寫入。

兩條示範動線的座標是策展後固定的戶外路徑。更新腳本不覆寫動線與示範條件，以免地圖變更自動改動測試材料。若道路變動，需由團隊重新查核並修訂。

輪行臺北原始寬度為公分，腳本轉為公尺。無效座標會排除，寬度 0、負值與未量測的 0/0 組合保留未知。建物中心與公開斜坡道點位均無實地查核資格。

## 接入實勘路線

### 使用網頁編輯器

1. 點右上角「實勘編輯」。第一次開啟會用兩條公開道路幾何建立空白草稿，所有模擬條件、照片、來源及查核日期均清空。入口位置仍需現場確認。
2. 選擇動線，再選 A 入口、路段或 B 入口。填寫數值時注意單位，未量測欄位繼續留白，已確認沒有階差或坡道才填 0。
3. 入口可直接輸入經緯度或點選地圖。若與路段端點距離超過 2 m，系統會提示。需要同步端點時須另外按按鈕，相鄰路段的查核狀態會取消，請重新查核。
4. 每個項目可加入最多 4 張 JPEG、PNG 或 WebP 照片，每張上限 2 MB，完整 JSON 上限 20 MB。填寫照片說明供檢視與輔助科技使用。照片會嵌入 JSON，CSV 只包含照片數量。公開分享前請自行檢查照片內容及來源授權。
5. 補齊量測、照片說明、實勘者與方式、有效的實勘日期後，勾選現場查核確認，按「標記本項已查核」。程式只檢查完整性，現場真實性由團隊核對。修改證據後須重新確認。即使每項紀錄已查核，含階梯、封閉、未知或不連續幾何的路線仍不符合候選條件。
6. 草稿會自動保存在此瀏覽器，也可按「儲存草稿」。若本機儲存失敗，畫面保留目前資料並提供匯出。無法讀取既有草稿時會暫停自動儲存，避免以新草稿覆寫，請匯入備份或手動儲存。
7. 匯出 JSON 備份，或交由團隊成員匯入續填。匯入會取代目前草稿，請先備份。格式不符時保留目前草稿。CSV 適合檢閱與彙整，重新匯入須使用 JSON。
8. 團隊完成現場複查與資料審核後，將匯出的 JSON 接到 `public/data/surveyed-routes.json`，重跑測試與建置後發布。編輯器不會將本機草稿自動混入已查核模式。

本機儲存以網站來源區分。本機開發網址與公開網址各有自己的草稿，更換裝置或瀏覽器需用 JSON 移轉。無痕模式及瀏覽器清理可能移除資料。

### 直接編輯檔案

1. 執行 `npm.cmd run survey:template`，取得 `public/templates/survey-template.json`。此指令只建立空白範本，所有通行條件均為 `null`，狀態為 `unverified`。
2. 複製範本，逐段核對道路與入口座標，填寫實際量測及照片。座標為 WGS84，順序是 `[經度, 緯度]`。每段起終點須與相鄰段銜接。
3. 將照片放入 `public/photos/`。`photos` 範例：`[{"src":"/photos/library-entrance.jpg","alt":"總圖入口坡道","caption":"實勘拍攝，填入拍攝日期"}]`。
4. 核對完成的入口與路段填入 `verifiedAt`、可追溯的 `source`，將 `status` 設為 `verified`。路段 `closed` 須明確填 `false` 才可列入候選。未量測欄位繼續保留 `null`。
5. 將完成資料放入 `public/data/surveyed-routes.json`，執行測試與建置，檢查已查核模式後再發布。保留原始實勘與複查紀錄。

| 路段欄位 | 單位與填法 |
| --- | --- |
| maxSlopePercent | 路段最大坡度，填百分比數值，例如 3 表示 3% |
| minWidthM | 最窄有效通行寬度，公尺 |
| stepHeightCm | 最大階差，公分 |
| hasStairs | 已確認無階梯填 false，有階梯填 true，未知填 null |
| rampLengthM | 坡道長度，公尺，已確認無坡道可填 0 |
| surface | 路面材質與狀況描述 |
| closed | 已查核未封閉填 false，封閉填 true，未知填 null |
| obstacles | 已知障礙描述陣列，並在原始實勘表中記錄查核情況 |
| verifiedAt | 真實查核日期，ISO 日期格式 |
| retrievedAt | 幾何或來源取得日期，與查核日期分開記錄 |

候選路線必須全程及兩端入口皆已查核、照片齊備、主要條件無缺值、無階梯、未封閉且幾何連續。示範資料沒有自動轉為已查核資料的功能。

手動與電動輪椅選項僅註記需求。系統依距離或最大坡度排序，未訂定個人的通行適用門檻。

## 差異與瓶頸解讀

比較摘要以畫面顯示的整數公尺計算距離差，以百分點表示坡度差，以公尺表示路寬差。任何一段缺少對應量測時，整條路線該項統計與差異均保留未知。

最陡與最窄標記代表具有該極值的整個路段。因目前紀錄僅保存路段量測，標記放在路段幾何中點，不代表測得極值的精確位置。多段並列時會全部列出。示範模式的瓶頸仍屬模擬數值。
