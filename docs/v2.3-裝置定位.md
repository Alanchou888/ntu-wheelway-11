# v2.3 裝置定位

2026-10-21

## 使用方式

1. 在路線畫面的地圖右側按「定位我」。開啟說明不會要求位置。
2. 按「同意並開啟定位」，由瀏覽器詢問是否允許位置存取。
3. 取得位置後顯示藍色位置點及誤差圓，狀態按鈕會標出裝置回報精度。
4. 拖動地圖可暫停跟隨，位置仍持續更新。按「回到我的位置」恢復地圖跟隨。
5. 按「停止定位並清除位置」會取消位置監聽，清除本頁位置點與記憶體資料。

切換到背景時會暫停取得位置，回來後需要按「繼續定位」。離開路線地圖或關閉頁面會釋放位置監聽。超過 30 秒沒有新位置時，舊點會改為灰色並顯示「上次位置，待更新」。拒絕權限、訊號無法使用、逾時及不支援定位都提供具體說明與手動重試。

## 資料與範圍

使用瀏覽器 `watchPosition`，只有使用者主動開啟時才呼叫，設定高精度偏好、最多 5 秒快取、12 秒逾時。高精度設定無法保證公尺級精度，實際由裝置與環境決定。介面呈現裝置回報的誤差範圍，超過 50 公尺會提醒比對地標。

位置只保留在目前頁面的記憶體，不寫入本站 API、localStorage、IndexedDB、分享 hash、社群回報或定位紀錄。不將位置當作起點，也不改動通行條件或實勘狀態。外部地圖服務仍會收到目前檢視區域的圖磚請求。

目前提供地圖定位與跟隨。尚未提供沿 GPS 位置判斷行進路段、偏離重算、轉彎提示、背景導航或同行者位置分享。路線預演使用獨立的「預演位置」，啟動預演會解除裝置位置的地圖跟隨，重新跟隨自己則暫停預演。

來源：[MDN Geolocation API](https://developer.mozilla.org/en-US/docs/Web/API/Geolocation_API)、[watchPosition](https://developer.mozilla.org/en-US/docs/Web/API/Geolocation/watchPosition)。需要安全連線與使用者允許，也可能受瀏覽器或宿主環境權限限制。

## 程式與瀏覽器驗證

自動測試涵蓋明確啟動、HTTPS 與裝置能力、停止及晚到的 callback、重新啟動、背景暫停、權限撤回、訊號錯誤、逾時、過期位置、跟隨切換、重複置中、亂序回傳及無效數值。定位畫面測試檢查精度、未知服務範圍及上次位置提示。

開發伺服器提供 `/__location-test` 測試頁，以固定公開校園座標模擬位置，不請求裝置位置或瀏覽器定位權限。畫面持續標示「定位開發測試，非裝置真實位置」。此頁與假定位提供器由正式建置移除。操作證據見 `evidence/v23-location-qa.json`，截圖 `evidence/v23-location-mobile-simulated.png` 僅表示模擬測試。

## 待團隊實機測試

尚未對本機使用者授予權限或讀取其真實位置。請在手機正式網址實測允許、拒絕、權限撤回、室外及室內精度、鎖定螢幕後恢復與不同瀏覽器。請記錄裝置與環境，勿以程式模擬結果代替真實使用者或戶外定位驗證。
