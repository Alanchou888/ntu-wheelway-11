# v2.1 路線預演與滿版地圖

2026-10-21。這次加入路線預演、互動路況時間軸與可調整高度的手機面板。

## 操作方式

1. 設定條件並比較路線，開啟其中一條路線。
2. 按「預演」沿原始道路幾何播放。預設每段結束暫停，亦可取消勾選連續播放。
3. 使用上一段、下一段、進度列或時間軸跳到路段。進度列支援方向鍵、Home 與 End。
4. 地圖位置、路段條件與照片會同步更新。按「檢視此段」可開啟完整量測與證據。
5. 手機以「地圖、摘要、展開」按鈕切換面板，亦可拖曳把手或使用把手的上下方向鍵。播放時自動收合，播放控制仍保留。

拖動地圖會解除跟隨，可按「跟隨」恢復。切換路線、反向動線或離開路線頁面會重設預演。瀏覽器切到背景會暫停，回來後由使用者決定是否繼續。開啟預演照片也會暫停。

## 資料界線

- 預演位置依路線幾何推進，不會取得裝置定位。
- 播放倍率只控制預演速度，不估算實際行進時間。
- 時間軸顯示路段最大坡度、最窄路寬與距離比例，沒有推算連續高程或安全評分。
- 任一路段缺少同類量測時，不宣稱全程最高或最窄。未知值顯示「未知」及「尚無資料」。
- 示範路線與入口持續標示。公開已查核路線仍為空，不加入模擬實勘結果或受測者紀錄。
- 系統啟用減少動態時停用動畫播放，逐段、時間軸與進度列仍可操作。
