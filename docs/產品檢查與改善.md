# 產品檢查與改善

檢查日期：2026-10-20。範圍為固定校園動線的試用版，涵蓋主要四步流程與團隊實勘編輯器。

## 本次改善

| 問題 | 改善與影響 |
| --- | --- |
| 舊版輔助字過小，英文眉標及口號佔用空間 | 改用直接的中文標題與較大的資訊字級，移除裝飾文字 |
| 導覽、流程與狀態堆疊 | 導覽整合到品牌列，手機流程與模式切換共用一列 |
| 路線分散在多張卡片，完整比較表佔用首屏 | 路線改為連續清單，數值差異保留，詳細表格可展開 |
| 路線只以相近的顏色區分 | 使用藍色實線與棕色虛線，加上文字圖例 |
| 小螢幕的模式按鈕被擠成直排 | 明確分配流程及模式切換寬度，實測主要控制項至少 44px |
| 關閉資料來源視窗後鍵盤焦點遺失 | 對話框關閉時還原呼叫者焦點，實測 Escape 可返回資料來源按鈕 |
| 無效量測可能讓使用者不確定保存結果 | 保留有效值、顯示欄位提示，離開欄位時還原並清除失效錯誤狀態 |
| 離線快取的 HTML 受到網站動態注入影響 | Service Worker 內嵌該版本建置 HTML，其餘資產與資料維持完整性驗證 |

## 驗證證據與範圍

- 93 項自動測試、TypeScript 檢查與正式建置通過。
- [16 項瀏覽器操作紀錄](evidence/v2-ui-qa.json)涵蓋主要流程、收藏重開與移除復原、分享、起終點交換、條件篩選、空白查核狀態、草稿保存、數字驗證、比較表及對話框焦點。
- 正式建置在瀏覽器顯示「離線清單已保存」，沒有未捕捉的 JavaScript 錯誤。
- 375px 手機未出現水平溢出，主要控制區至少 44px。另檢查 844px 手機橫向，未出現水平溢出。
- 設定畫面 46 個文字節點的樣本對比均達相應文字門檻。此量測未含外部地圖圖磚標籤，也未涵蓋所有互動狀態，完整 WCAG 與輔助科技檢查仍待執行。
- 離線中斷、版本一致性與更新保護已有 Service Worker 模擬測試。尚未在實機切斷網路，不能據此宣稱所有裝置均可完整離線。

原先的 v1.1 截圖、瀏覽器腳本及紀錄仍保留供追溯，操作文字和選擇器會隨版本改動。自動驗證紀錄不屬於真實受測者紀錄。

## 後續產品工作

1. 團隊實際走訪兩端入口及全程路段，補量測、照片、來源與查核日期，再使用實勘發布檢查工具審核。
2. 由輪椅使用者操作手機版，記錄是否能理解示範與查核模式、選路差異及空值。
3. 在實機及螢幕閱讀器檢查照片放大、200% 文字、離線中斷、多分頁衝突及資料匯入失敗。
4. 取得穩定的資料維護責任與查核流程後，再評估協作後端、施工回報及擴充校園範圍。

本次維持無登入的靜態網站。收藏與實勘草稿存於各自瀏覽器，尚未提供跨裝置自動同步。
