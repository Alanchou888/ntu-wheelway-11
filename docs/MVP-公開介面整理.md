# MVP 公開介面整理

公開網站用來查看第 11 組試走的去程、回程，以及每個實勘點的照片、觀察與單點量測。首頁直接選擇方向。

| 項目 | 原公開介面 | 本次調整 |
| --- | --- | --- |
| 選路 | 起終點表單、四步流程、兩種資料模式 | 首頁同時提供去程與回程。進入路線後可看沿途實勘，另可分享、收藏或列印。 |
| 個人化條件 | 輪椅類型、坡度、寬度、階差、查核天數、避開近期受阻回報 | 公開介面暫停這些選項。路況仍可查閱與回報。已知的舊分享連結可重開，停用的參數不會篩掉去回程。 |
| 地圖 | 四個圖層及一整排分類 | 保留路線、路況與設施圖層。整段坡度無資料時隱藏坡度圖層。實勘點和坡道放在快捷列，飲水、廁所、電梯、休息、建物與地標可從「更多設施」開啟。 |
| 地點搜尋 | 搜尋、附近分類及空結果 | 空白搜尋可開啟地點清單。廁所和坡道分類包含已記錄的實勘點。缺少飲水等點位時，清單會說明目前沒有資料。 |
| 路段資訊 | 查核欄位、來源與技術提示分散在多處 | 以現場紀錄、照片及紀錄日期為主。「全段通行資料」標出缺少的量測。 |
| 使用說明與狀態 | 開發、審核、來源日期及離線快照常駐 | 三步使用指南，來源和日期收在「資料說明」。離線或有新版可更新時才顯示網站狀態。 |
| 實勘工具 | 公開導覽及空白範本下載 | 團隊透過本機入口使用編輯器和空白範本。 |

## 團隊入口

在有專案原始碼的團隊電腦執行 `npm.cmd run team`，再開啟 `http://127.0.0.1:5173/team`。服務只監聽本機回環位址。公開產物不包含編輯器和空白範本，部署的 `/team` 與舊範本網址會回傳 404。

編輯器仍可匯入及匯出 JSON、匯出 CSV、儲存本機草稿及複查實勘資料。可從團隊入口下載 [空白 CSV](templates/field-survey.csv) 與 [空白 JSON](templates/survey-template.json)。既有草稿仍由原瀏覽器及來源網址保存。跨網址或裝置移轉時使用 JSON 備份。若舊的正式站編輯分頁仍開著，可從該分頁匯出。

已查核資料的結構、篩選規則、審查指令及社群管理端點保留於程式與團隊流程。參考 [資料維護](資料維護.md) 和 [實勘發布流程](實勘發布流程.md)。

## 使用者仍看得到的限制

- 路線畫面說明這是總圖與博雅的試走紀錄，部分通行條件尚未確認。館內虛線表示約略走向。
- 98、89、78 公分等單點寬度保留「約」與量測方法。手機傾角保留原始讀值。全段未知欄位顯示無資料。
- 定位需先同意。送出社群回報前會提示文字、照片與選定地點的公開範圍。地圖、照片或路況載入失敗時有提示或重試入口。

這份紀錄記載受測前的介面整理。正式使用者測試的行為與回饋可另填在 [使用者測試紀錄](使用者測試紀錄.md)。
