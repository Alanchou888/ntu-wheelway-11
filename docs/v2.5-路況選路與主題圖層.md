# v2.5 路況選路與主題圖層

2026-10-22

## 障礙位置

登入回報時可在所選路段的小地圖點選位置、拖曳標記，或按「選取路段中點」後使用方向按鈕每次微調 2 公尺。位置為選填，切換路段會清除原標記。關閉社群視窗會保留尚未發布的表單，重新開啟可繼續。

前後端都驗證落點需在所選路段幾何 30 公尺內。座標保存為六位小數，這是儲存精度，並非現場定位準確度的保證。發布前有公開位置提示，網站不會讀取或自動帶入裝置 GPS。舊回報及未指定位置的回報維持整段道路標記。

單一驚嘆號標記表示使用者選擇的落點，有數字的標記表示未指定位置的整段回報數量。所有標記可用鍵盤開啟，清單保留對應資訊。未經實勘的標記不會自動變成已查核資料。

## 回報參與選路

設定及比較畫面新增「避開近期受阻回報」，預設關閉。開啟後，先套用既有資料模式與量測限制，再排除有近期「通行困難」或「無法通行」回報的候選動線，其餘動線依原本距離或最大坡度偏好排序。

- 每條被排除的路線列出問題類別與相關路段。
- 過期、有人回報已排除及有不同現場回報的內容保留提示，沒有直接成為排除依據。
- 同一個回報最多計算一次。精準位置也會比對其他動線附近 8 公尺內的路段，整段回報會比對共享的道路長度。這是保守的幾何比對，校園平行通道仍需團隊核對。
- 社群讀取失敗或距上次成功取得超過 5 分鐘，會說明需要更新，暫不提供符合避開條件的候選結果。可重新整理或關閉該條件。
- 社群服務目前最多提供最近 300 則回報，超過時介面會說明本次資料範圍。
- 零筆回報表示目前沒有取得回報，通行狀態仍待確認。

避開設定與地圖主題可保留於路線 hash 連結，舊連結繼續有效。儲存個人偏好時也會保存避開設定，仍限本瀏覽器。無論有多少回報，示範路線都不會通過已查核模式。

本版仍只篩選兩條既有動線，未實作任意地址路網或即時重新計算繞行幾何。

## 地圖主題

從「地圖圖層」切換路線、路況、坡度及設施四個主題。

| 主題 | 呈現內容 |
| --- | --- |
| 路線 | 原有藍色／棕色動線、瓶頸與可選圖層 |
| 路況 | 依近期回報的通行影響呈現路段，保留落點與整段標記 |
| 坡度 | 依路段最大坡度分類，≤ 3%、> 3% 至 5%、> 5% 及未知以顏色、線型及文字區分 |
| 設施 | 突出公開設施點位，可查看來源，資料尚缺的分類持續說明 |

坡度分類為閱讀用途，沒有套用通行法規標準或產生無障礙評分，沒有推算連續高程。示範模式圖例持續標示示範數值。未知值保持未知。主題選單支援鍵盤，Escape 關閉並還原焦點。切換主題後回到圖層按鈕，手機會收合資訊面板以顯示地圖。

## 資料遷移與驗證

`drizzle/0001_thin_inertia.sql` 只新增可為 null 的經緯度欄位，保留原回報、照片與確認資料。Sites 發布流程會先套用遷移，再上傳 Worker。開發資料庫與公開資料庫分開。

183 項自動測試通過，包含原有功能及新落點驗證、共享路段、時效、爭議狀態、兩／一／零條候選路線、量測限制、hash 與圖例語意。TypeScript 檢查與正式建置通過。

獨立本機 Worker、D1 的 11 項整合測試紀錄見 `evidence/v25-api-qa.json`。重跑方式如下，腳本只接受 loopback HTTP，拒絕公開網址，測試紀錄均為自動測試資料。

```powershell
node scripts/conditions-api-qa.mjs http://127.0.0.1:8787
```

公開站 14 項介面檢查見 `evidence/v25-public-ui-qa.json`，涵蓋版本更新、回報避開、主題切換、圖例、375px／390px 手機版、按鈕尺寸、路段／確認流程、連結重開及 Escape 焦點還原。截圖見 `evidence/v25-public-desktop.png` 及 `evidence/v25-public-mobile.png`。檢查沒有向公開站發布測試回報。

本輪本機預覽分頁曾被瀏覽器存取政策阻擋，已改於公開站檢查上述可匿名操作的功能。登入後的小地圖點選、拖曳與實機操作尚未完成瀏覽器驗收，其資料驗證及後端權限由自動測試與本機 API 整合檢查涵蓋。真實輪椅使用者、室外 GPS、現場資料及輔助科技仍需團隊實際驗收。
