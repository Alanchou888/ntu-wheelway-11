# 後續修改介面的提示詞

可在已安裝 Frontend Design 與 UI UX Pro Max 的環境使用。先閱讀專案根目錄的 DESIGN.md，再針對明確畫面修改。

```text
請直接改善輪行臺大的既有介面。先閱讀 DESIGN.md、package.json，以及目標畫面的元件和樣式。

這是一個繁體中文、手機優先的校園輪椅選路工具。使用者要比較總圖書館與博雅教學館之間的距離、坡度、路寬、入口及查核證據。

使用 Frontend Design 檢查視覺層級與文字，使用 UI UX Pro Max 查詢這次修改真正涉及的互動或響應式規則。每項建議要先確認適合地圖工具。整頁設計結果若是行銷頁，請明確排除。

請把功夫放在字級、字重、間距、對齊、表單、選取狀態與地圖比例。避免裝飾性英文標題、口號、卡片套卡片、漸層背景、大量膠囊標籤與無意義動畫。主要功能靠文字和語意控制清楚呈現。

保留資料模式、來源署名、示範入口提示、未知值及查核日期。不可創造實勘結果，不可將收藏或本機草稿變成公開查核資料。

實作後實際打開頁面，檢查桌面與小手機、鍵盤操作、焦點、44px 主要點擊區、文字換行、失敗狀態與四步返回流程。修正看得見的問題，附實際頁面截圖，清楚區分本地驗證與公開部署狀態。
```
