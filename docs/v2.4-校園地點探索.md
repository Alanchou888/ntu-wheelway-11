# v2.4 校園地點探索

2026-10-21

## 已實作

搜尋列支援名稱、別名、英文與「臺／台」變體。輸入時顯示建議，方向鍵移動、Enter 選取、Escape 收起。清除後可返回原本的路線規劃。最近查看只保存本瀏覽器最多 8 個地點 ID，可清除，不保存搜尋字串或 GPS 位置。

地圖上的地點標記與建物輪廓可開啟地點卡片。標記提供文字標籤與鍵盤操作，清單提供相同的資訊入口。選取時顯示建物輪廓或位置點，依目前可見地圖範圍調整鏡頭。地圖點位隨縮放與目前視野呈現。

卡片顯示地點類別、公開資訊、資料來源與取得日期。地址、開放時間、輪椅標記及照片未提供時保留未知。建物代表位置與入口分開列出。公開輪椅標記持續標示未經團隊實勘，原始營業時間未自動判讀為目前開放。

總圖與博雅的「從這裡出發／前往這裡」會設定既有的起終點，保留資料模式、輪椅需求、個人條件與偏好。其他地點可查看位置與分享，路線按鈕會停用並說明尚未接通。

地點與分類可保留在 hash 連結，分享地點可直接重開卡片。舊版路線連結仍可使用。地點分享不含裝置位置。

手機保留地圖、摘要、展開三段面板，主要按鈕至少 44px。分類列可橫向捲動，地圖工具改為一列，圖層選單在面板上方顯示。地點卡片關閉後返回相關資訊，不會自動重新開啟搜尋建議。

## 公開資料與限制

目前快照包含 88 個地點：65 個建物、5 個地標、18 個公開斜坡道。建物及地標使用既有臺大 API、OpenStreetMap 校園快照，坡道來自輪行臺北。各筆取得日期沿用原始快照，整理日期不視為新下載或實地查核日期。

本次 Overpass 主站與鏡像查詢未取得有效資料。廁所、電梯、飲水與休息類別會明確說明資料暫未取得，不填入虛構設施，也不將零筆結果解釋為現場沒有設施。

`scripts/refresh-places.mjs` 只查詢固定校園範圍。成功時匯入公開設施標記，排除已標示私人、禁止使用、停用、無效座標或重複的資料。更新失敗保留先前有效快照與原取得日期。未有設施快照時，保留既有建物、地標與坡道資料。

```powershell
npm.cmd run places:refresh
npm.cmd run places:refresh -- --offline
```

瀏覽者讀取同站 `data/places.json`。若地點檔案載入失敗，仍可使用校園基本資料的總圖、博雅及坡道，提供重試與返回操作。地點資料也納入既有同版本離線外殼。

資料依據：[OpenStreetMap Overpass API](https://wiki.openstreetmap.org/wiki/Overpass_API)、[輪椅標記定義](https://wiki.openstreetmap.org/wiki/Key:wheelchair)、[飲水點標記](https://wiki.openstreetmap.org/wiki/Drinking_Water)。© OpenStreetMap contributors，ODbL。既有臺大及輪行臺北來源與日期保存在各筆快照。

## 驗證範圍

自動測試涵蓋搜尋排序與別名、分類、零筆資料、未知值、未接通地點、起終點設定、模式與條件保留、hash 相容、最近查看與儲存失敗、來源日期、公開點位篩選及 API 失敗保留快照。
