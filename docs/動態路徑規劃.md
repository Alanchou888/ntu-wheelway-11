# 臺大與周邊路徑規劃

從首頁按「規劃新路線」，搜尋起終點，或按欄位旁的圖釘從地圖選點。選定兩點後會自動計算，同一對起終點可能有 1 至 3 條候選路線。原有的總圖與博雅去回程可從「示範路線」查看。

本階段採用 Geofabrik 的 OSM 快照、[ngraph.path](https://github.com/anvaka/ngraph.path) 的 A* 與 [ngraph.graph](https://github.com/anvaka/ngraph.graph) 的圖結構。小範圍只需取得同站資料，不消耗外部 Routing API 額度，也可按近期回報與已知路況調整權重。

## 範圍與結果解讀

- 快照四界為東經 121.5338–121.5446、北緯 25.0116–25.0220，資料日期為臺灣時間 2026/11/17 05:22。共有 4,882 個節點及 1,480 段道路。這版有 224 段標示路面、4 段標示寬度、6 段標示平整度、6 段有輪椅標籤，缺少可解析的坡度數值。可在網站下載路網快照。
- 依 OSM 共享節點接續道路，保留步行方向，排除已標階梯、限制通行、封閉與未確認的室內道路。接入點距選點最多 40 公尺。路外選點若遇到最近的步道不相通，可改用同距離範圍內可連上的地面步道。距離從接入點起算，地圖不補畫選點到道路的連線。
- 最短偏好以距離計算。其他偏好使用 `src/routing-plan.ts` 的權重，考慮公開標籤、路況回報和資料缺口；有足夠不同的替代走法才會顯示。時間以 3 km/h 估算。
- 逐段內容分為公開標記、圖上與試走線重疊、附近的團隊觀察及近期回報。單點照片與量測可在實勘卡片查看。距離、估時與公開屬性均有資料範圍限制。
- 規劃路線可分享與收藏。連結保留選點、偏好與選中的候選路線，重開時會依目前路網和回報重算。裝置定位仍需使用者授權。
- 從逐段資訊按「回報這一段」，或從「路況」按「在地圖選回報位置」。登入後可公開標記、觀察、單點量測與照片。其他使用者可補充或核對。新的路網受阻點獲其他使用者確認仍存在後，才會被規劃避開。單點量測留在回報卡。
- 「記錄沿途實勘」仍可儲存個人草稿及下載 JSON。「示範練習」可用模擬情境試做回報及核對，練習資料只留在當前頁面。

## 更新方式

執行 `npm.cmd run routes:refresh` 向 Overpass 取得臺大周邊路網。下載、驗證或寫入失敗會保留上一版。需要從 Geofabrik 更新時，可用 pyosmium 本機擷取 PBF。

```powershell
python -m pip install osmium
python scripts/extract-routing-osm.py taiwan-latest.osm.pbf campus-osm.json
npm.cmd run routes:refresh -- --input campus-osm.json
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
```

只提交 `public/data/routing-network.json`。更新後重跑實際路線與分享連結的檢查。規劃範圍、入口與坡度、路寬資料，優先透過團隊實勘再逐段補充。
